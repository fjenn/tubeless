Good to know

Tubeless runs inside youtube.com in your own browser and uses the YouTube account you're signed in with there, like youtube.com itself. Nothing goes through us: only YouTube and the services the app already uses (SponsorBlock, Return YouTube Dislike). It loads the newest Tubeless each time, so the bookmark never needs updating. To use it signed out, turn off Settings → Account → "Use my youtube.com sign-in". The source is public.

Prefer an app? The Tubeless app and the browser extension do the same.
